# Objectives

## Learning outcomes

- Explain x86-64 boot and privilege transitions using a cited specification.
- Explain how a \`no_std\` kernel starts, handles faults, and owns physical and virtual memory.
- Build and validate one small capability at a time under QEMU when implementation is authorized.
- Use Rust's type and ownership system where it helps, and document invariants around necessary unsafe operations.
- Define observable acceptance evidence for tasks, processes, storage, syscalls, and a basic shell.

## Engineering outcomes

Keep boundaries explicit, minimize hidden dependencies, record decisions and failed experiments, and make every completed milestone reproducible. These are goals; no implementation outcome is currently claimed. See the [roadmap](../../ROADMAP.md).
