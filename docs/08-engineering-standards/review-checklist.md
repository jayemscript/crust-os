# Review checklist

## Documentation changes

- [ ] Scope matches the request; unrelated files and the license are untouched.
- [ ] Links resolve relative to their containing document and index navigation is updated.
- [ ] Facts have appropriate citations; proposals, assumptions, and questions remain distinguishable.
- [ ] Status and checkboxes match actual evidence; no unimplemented feature is described as working.
- [ ] The decision log and progress tracker reflect consequential changes.
- [ ] No unrequested generated files, logs, Cargo files, source files, or .pnpm-store appear during foundation work.

## Future authorized implementation

- [ ] Phase prerequisites and decisions are resolved or explicitly bounded.
- [ ] ABI, hardware, memory ownership, and unsafe invariants are reviewed.
- [ ] Normal and failure behavior are demonstrated in the documented environment.
- [ ] Validation record states tool versions, expected and observed results, and limits.
- [ ] Phase status changes to Completed only when its acceptance criteria are met.
