# Experimental ideas

Experiments are optional and must not become prerequisites by accident. Each proposed experiment should have a question, smallest setup, expected observation, failure signal, and a decision it could change.

- Compare serial output with another early diagnostic channel after boot choice.
- Measure a polling versus interrupt-driven input path once interrupt handling is reliable.
- Compare a simple frame bitmap with a free-list design using the same memory-map fixtures.
- Evaluate a cooperative task runner before timer preemption.
- Explore a read-only in-memory file image before persistent writes.

All ideas are **Not Started**. Any implementation requires a phase-specific authorization and a documented risk review.
