# Milestones

The [roadmap](../../ROADMAP.md) is the canonical dependency and acceptance summary; the [phase files](../README.md#development-phases) contain task details. No completion dates are assigned.

| Milestone group | Phases | Current state | Gate to next group |
| --- | --- | --- | --- |
| Documentation foundation | 00 | Completed — documentation only | Review navigation, scope, and open decisions |
| Boot and kernel diagnostics | 01–02 | Not Started | Observable entry and failure path |
| CPU and memory control | 03–04 | Not Started | Exception, mapping, and protection evidence |
| Execution and devices | 05–06 | Not Started | Task progress and required device I/O |
| Storage and user boundary | 07–08 | Not Started | Checked file reads and rejected invalid syscalls |
| User interaction | 09 | Not Started | Bounded shell interaction |
| Optional extensions | 10–11 | Not Started | Separate proposal and authorization |

Review gates are evidence-based and may be revised through a [decision record](decision-log.md).
