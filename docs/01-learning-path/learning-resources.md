# Learning resources

These are starting points, not evidence that a particular design has been selected:

- [The Rust Book](https://doc.rust-lang.org/book/) for ownership, traits, and error handling.
- [Rust Reference](https://doc.rust-lang.org/reference/) for language and unsafe semantics.
- [Embedded Rust Book: \`no_std\`](https://doc.rust-lang.org/embedded-book/intro/no-std.html) for bare-metal runtime constraints.
- [AMD64 Architecture Programmer's Manual, Volume 2](https://docs.amd.com/v/u/en-US/24593_3.44_APM_Vol2) for system programming.
- [UEFI specifications](https://uefi.org/specifications) for firmware interfaces.
- [QEMU system documentation](https://www.qemu.org/docs/master/system/index.html) for emulation behavior.

Record the specific section and revision used for any consequential claim in [research references](../06-research/references.md).
