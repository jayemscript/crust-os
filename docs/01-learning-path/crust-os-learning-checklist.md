# CrustOS — 12-Week Low-Level Programming Learning Checklist

**Goal:** Learn the foundations of computer architecture, boot processes, Rust systems programming, and operating system engineering while developing CrustOS.

**Suggested study split:** 60% learning and 40% applying concepts to CrustOS.

> This is a flexible part-time learning plan, not a deadline. Some kernel topics may take longer.

## Weeks 1–2 — Computer Architecture

**Resources:** [Nand2Tetris](https://www.nand2tetris.org/) and [Ben Eater](https://www.youtube.com/@BenEater)

- [ ] Understand CPU, RAM, registers, and machine instructions.
- [ ] Learn binary, hexadecimal, and bitwise operations.
- [ ] Understand how a CPU executes instructions.

## Weeks 3–4 — BIOS, Bootloaders, and Rust

**Resources:** [OSDev Wiki](https://wiki.osdev.org/Getting_Started) and [Writing an OS in Rust](https://os.phil-opp.com/)

- [ ] Learn BIOS vs UEFI and the boot process.
- [ ] Understand `no_std`, `no_main`, and panic handlers.
- [ ] Trace how CrustOS reaches `kernel_main()`.

## Weeks 5–6 — Assembly and Execution

**Resource:** [OpenSecurityTraining2](https://opensecuritytraining.info/)

- [ ] Learn x86-64 registers and stack frames.
- [ ] Understand instructions, interrupts, and privilege levels.
- [ ] Study Rust disassembly using debugging tools.

## Weeks 7–8 — Kernel Memory Management

**Resource:** [Writing an OS in Rust](https://os.phil-opp.com/)

- [ ] Understand physical and virtual memory.
- [ ] Learn paging and page tables.
- [ ] Study heap allocation and frame allocation.

## Weeks 9–10 — Interrupts and Hardware

**Resources:** [OSDev Wiki](https://wiki.osdev.org/) and [MIT Operating System Engineering](https://pdos.csail.mit.edu/6.S081/2025/schedule.html)

- [ ] Understand exceptions, the Interrupt Descriptor Table (IDT), and faults.
- [ ] Learn keyboard input and hardware interrupts.
- [ ] Design a simple kernel logging system.

## Weeks 11–12 — Operating System Services

**Resource:** [MIT Operating System Engineering](https://pdos.csail.mit.edu/6.S081/2025/schedule.html)

- [ ] Understand processes, threads, and scheduling.
- [ ] Learn system calls and user/kernel separation.
- [ ] Plan a tiny shell and framebuffer drawing API.
