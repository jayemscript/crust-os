# Operating-system theory learning path

Read about mechanisms before policies: address spaces before allocation strategy; context switching before scheduler fairness; device I/O before file abstractions; privilege transitions before syscall API design.

## Questions to answer

- What state belongs to a task, a process, and the kernel?
- How do exceptions, interrupts, and system calls differ?
- What isolation properties depend on page tables and CPU privilege?
- What must a scheduler save and restore?
- How does a file-system interface separate names, files, and block devices?

Use the [roadmap](../../ROADMAP.md) to match each topic to a milestone. Treat textbook models as explanations and verify hardware-specific claims against primary specifications.
