# Research workspace

The canonical research summaries and citations live in [docs/06-research](../docs/06-research/references.md). Use this directory only for future, explicitly requested Markdown research notes that do not fit those summaries. Do not add downloaded specifications, generated output, or unreviewed claims.

For each note, identify the question, source and revision, findings, limits, and which [decision](../docs/09-project-management/decision-log.md) or phase it informs. No research artifact beyond this guide is currently required.
